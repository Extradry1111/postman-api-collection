Collection Description
API test collection for automationexercise.com — covers product/brand catalog endpoints and the full account lifecycle (create, login, update, delete), including negative cases (wrong HTTP verb, missing required parameters). Companion project to the Playwright automation framework in the same portfolio — same API, validated two ways: as executable TypeScript tests (CI-integrated) and as a Postman/Newman collection (the tool many teams still use for quick manual API checks and smoke suites). Both should agree on expected behavior; if they ever don't, that's worth investigating on its own. Run order matters: 'Create Account' must run before 'Verify Login (valid)', 'Get User Detail', 'Update Account', and 'Delete Account (cleanup)', since those depend on the account it creates. Newman/Collection Runner executes folders top-to-bottom, so the numbered folder prefixes (01, 02, 03) enforce that order.
